SECTION 1: PROJECT OVERVIEW
================================================================================

1.1 PRODUCT DEFINITION
----------------------
EduLens is an AI-powered smart glasses platform for elementary education (ages 
6-12). The system provides real-time homework assistance through:
  - Integrated camera for visual capture of learning materials
  - On-device AI OS for context recognition and adaptive tutoring
  - Audio-based explanations via built-in speakers
  - Hands-free, voice-activated interaction

1.2 DEVELOPMENT SCOPE
---------------------
This specification covers Phase 1 (Home Learning) development:
  - Core AI tutoring system
  - Vision processing pipeline
  - Voice interface system
  - Parent companion application
  - Privacy and safety infrastructure

1.3 SUCCESS CRITERIA
--------------------
  - [ ] AI can accurately recognize 95%+ of elementary-level printed text
  - [ ] AI can recognize 85%+ of child handwriting samples
  - [ ] Response latency < 2 seconds from query to audio output
  - [ ] 4+ hours battery life under active use
  - [ ] COPPA compliance certification ready
  - [ ] Parent app functional with progress tracking

SECTION 4: COMMUNICATION PROTOCOLS
================================================================================

4.1 MESSAGE FORMAT
------------------
All inter-agent communication uses JSON:

{
  "message_id": "uuid-v4",
  "timestamp": "ISO-8601",
  "from_agent": "AGENT_ID",
  "to_agent": "AGENT_ID | BROADCAST",
  "message_type": "TASK_ASSIGNMENT | STATUS_UPDATE | COMPLETION | ERROR | QUERY",
  "payload": {
    "task_id": "string",
    "status": "PENDING | IN_PROGRESS | BLOCKED | COMPLETED | FAILED",
    "data": {},
    "error": null
  }
}

4.2 STATUS REPORTING
--------------------
Agents report status every 5 minutes (simulated) or on state change:

{
  "agent_id": "AGENT_ID",
  "current_task": "TASK_ID",
  "progress_percent": 0-100,
  "blockers": [],
  "estimated_completion": "ISO-8601",
  "resource_usage": {
    "tokens_used": int,
    "api_calls": int
  }
}

4.3 ERROR HANDLING
------------------
On error, agents must:
  1. Log error with full context
  2. Notify orchestrator immediately
  3. Attempt recovery if possible
  4. If unrecoverable, mark task FAILED with detailed explanation

Error escalation:
  - Minor (recoverable): Log and retry
  - Major (blocking): Notify orchestrator, await instructions
  - Critical (system): Halt and alert all agents

4.4 ARTIFACT HANDOFF
--------------------
When a task produces artifacts for another agent:
  1. Producer writes to designated output path
  2. Producer sends COMPLETION message with artifact manifest
  3. Orchestrator validates artifacts exist
  4. Orchestrator notifies dependent agents
  5. Consumer acknowledges receipt

SECTION 9: EMERGENCY PROCEDURES
================================================================================

9.1 AGENT FAILURE
-----------------
IF agent becomes unresponsive:
  1. Orchestrator attempts 3 restarts (30s intervals)
  2. If still failed, reassign tasks to backup agent
  3. Log full state for debugging
  4. Notify all dependent agents of delay

9.2 CRITICAL BUG DISCOVERED
---------------------------
IF security/safety bug found:
  1. HALT all dependent work immediately
  2. Prioritize SEC-001 for investigation
  3. Do NOT proceed past affected milestone
  4. Full audit required before resume

9.3 RESOURCE EXHAUSTION
-----------------------
IF resource limits approached:
  1. Pause non-critical tasks
  2. Prioritize critical path
  3. Request resource increase from orchestrator
  4. Resume when resources available
